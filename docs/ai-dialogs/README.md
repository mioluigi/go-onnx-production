# AI dialogs (assignment deliverable, spec FR-14)

The conversations with AI assistants used to build this project, saved as PDF.
How each tool was used is described in the main [README](../../README.md#how-this-project-was-built);
the author used his existing Claude Pro and Gemini Ultra subscriptions.

| File | Assistant | What it covers |
|---|---|---|
| [`claude-build-dialog.pdf`](claude-build-dialog.pdf) | Claude (Anthropic) | The whole build conversation: requirements and rubric, constitution, specification, spike, plan and tasks, then every task from scaffolding to README, with the author's decisions and approvals. Terminal output the author pasted as attachments is not shown in the printout; what it showed is summarized in the replies, and its effects are in the commit history. |
| [`gemini-spec-review.pdf`](gemini-spec-review.pdf) | Gemini (Google) | Independent review of the draft specification; triage in [`docs/reviews/001-spec-review.md`](../reviews/001-spec-review.md). |
| [`gemini-t20-repository-review.pdf`](gemini-t20-repository-review.pdf) | Gemini (Google) | Independent review of the finished repository against the rubric (task T20); triage in [`docs/reviews/002-repository-review.md`](../reviews/002-repository-review.md). |
